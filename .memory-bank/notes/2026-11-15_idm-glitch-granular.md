# IDM: glitch / granular notes

- IDM complexity comes from manual sequencing, not layer count; 3–4 foreground
  layers with deliberate hits beat 10 random ones.
- Granular in Strudel: `begin/end` set the window, `chop(n)` cuts it, `fast`
  sets density, `pan(rand)` scatters. Keep the cloud dry (`room ≤0.2`).
- Transients + large grains = flamming; use short windows for drums, long
  windows and low density for pads.
- 8-bit = pulse duty + fast `arp(run(n))` + `crush`. `crush` is a worklet per
  event, so only on sparse layers.
- Acid: glide only on selected 16ths (gate without `<…>`); wide intervals,
  3–5 notes per bar, no chord arpeggiation.
- Fat rough bass = sub ≤80 + separate mid growl (150–400 Hz) + FM rubber.
  `shape` before `gain`; drive up, trim down.
- Dark IDM: tritone axis + `@dark` for anchored phrases; minor seconds are
  still errors. Separate registers: bass c1–db2, pad c3–e4, lead c5–f6.
- Performance: 8 switches + 6 momentary pads + 2 scenes; change one thing per
  8-bar phrase, not everything at once.
- Rhythm mutation: `mutate` keeps random ghosts, `fill` adds a 32nd snare fill;
  modes 4–7 (skitter/shuffle/poly/fracture) use every drum layer.
- Granular source can move: a `padlong/space/wind/noise2` bank in AUTO changes
  every 4 bars; pitch −24…+12 gives two octaves down without touching speed.
