# Psytrance — подводные камни и «как не надо»

Это чеклист, которого не хватало перед первыми попытками. Каждый пункт:
**симптом → почему → что делать вместо**. Плейбук — [`README.md`](README.md);
код — [`strudel-recipes.md`](strudel-recipes.md).

## 1. Значения и звук

### Копирование DAW cutoff/Q в Strudel
- **Симптом:** acid кричит, бас свистит, микс тонкий или болезненный.
- **Почему:** в DAW-гайде «cutoff 400–1000, Q 12–15»; в Strudel `lpf` — Гц,
  `lpq` — реальный Q 0–50. Q 12–15 — это крайность, а не дефолт.
- **Вместо:** начинай с Q 0–4; acid — **низкий base + глубокая огибающая**
  (например, 120 Гц + 4.5 октавы + ladder), а не высокий base + 1.5. Настраивай
  на слух, а не по скриншоту из DAW.

### Высокий base + мелкая огибающая у acid
- **Симптом:** 303 звучит как статичная пила, без «запаха».
- **Почему:** высокий base не даёт фильтру закрыться в тёмную точку; мелкая
  огибающая почти не двигает.
- **Вместо:** base 80–200 Гц, `lpenv` 3–5, `lpd` 0.05–0.15, `lps` 0–0.2,
  `ftype('ladder')` для характера 303. Потом — медленный LFO на base.

### Статичный срез
- **Симптом:** синт звучит как пресет; скучно даже с правильными нотами.
- **Почему:** нет движения, нет автоматики/LFO.
- **Вместо:** `lpf(base × sine.range(...).slow(16) × autoAt(...))` для коротких
  ивентов; `lpdepth`/`lpsync` для длинных пэдов/струнных. Двигается каждый
  синт.

### Дисторшн вместо движения фильтра
- **Симптом:** всё громко и грязно, но всё равно тускло.
- **Почему:** `distort` добавляет гармоники, а не движение.
- **Вместо:** лёгкий drive (0–2) + движущийся фильтр; acid может быть чистым.

### `roomsize` >10 / несколько ревербов
- **Симптом:** размытый длинный хвост, скачки CPU.
- **Почему:** в Strudel `roomsize` 0–10; большой hall — не пси-комната.
- **Вместо:** один общий `fx.reverb.size` (6–9), короткая комната; `room`
  0.1–0.5 по слоям. Не меняй size по секциям.

### Worklet-штормы / supersaw-стеки
- **Симптом:** треск, дропауты, CPU на слабых машинах.
- **Почему:** `ftype('ladder')`, `distort`, `crush`, `shape` — один worklet на
  ивент; `supersaw` разворачивается в много осцилляторов.
- **Вместо:** худшая секция до ~150 worklet/с (`npm run cpu`); без ladder/
  distort на плотных 16-х; без supersaw-стеков на плотных партиях.

## 2. Кик и бас

### Длинные бас-ноты / sustain
- **Симптом:** низ превращается в дрон, нет роллинга.
- **Почему:** sustain и отсутствие зазора; ноты перекрывают кик и друг друга.
- **Вместо:** 50–75 мс, attack 1–3 мс, **sustain 0**, release 20–40 мс; нота
  умирает до следующей. 12 нот на такт, три 16-х между киками.

### Бас на бочке
- **Симптом:** кик и бас дерутся, нет панча.
- **Почему:** первая 16-я занята киком; бас тоже попадает туда.
- **Вместо:** `~ x x x` на каждую четверть; даунбит — кику. Если линия
  непрерывная, дакай её (orbit 2) и укорачивай.

### Нет разделения sub/top
- **Симптом:** бас либо мутный, либо тонкий.
- **Почему:** один слой пытается быть и сабом, и mid-басом.
- **Вместо:** sine-саб на корне (40–80 Гц) + saw/square top (300–600 Гц) с
  быстрой огибающей; моно ниже ~200 Гц; сатурация только на top.

### Нет зазора / нет сайдчейна
- **Симптом:** «насос» или стена низа.
- **Почему:** хвост кика наезжает на бас; нет дака или его слишком много.
- **Вместо:** короткий кик (<100 мс) + сайдчейн 2–4 дБ с быстрым release, к
  первой бас-ноте — в ноль. Если насос слышно, это уже не psy.

### Бас настроен в кик
- **Симптом:** два саба бьются.
- **Почему:** кик и бас на одном фундаментале.
- **Вместо:** фундамент кика на полутон-два в стороне от корня баса; хвост
  кика короче.

## 3. Acid, лиды и риффы

### Попытка написать аккордовую прогрессию
- **Симптом:** звучит как трансовый поп; гипноз исчезает.
- **Почему:** psytrance — один корень; аккорды/обыгрывание — другой жанр.
- **Вместо:** статичный корень + дрон + интервалы. Если нужно движение —
  меняй одну ноту раз в 8–16 тактов, а не 4-аккордовую петлю.

### Acid с кучей разных нот / прыжков
- **Симптом:** «acid» звучит как случайная мелодия, нет гипнотической ячейки.
- **Почему:** много питч-классов и октавных скачков; нет повтора.
- **Вместо:** ритмично повторяй одну ноту; m2/m3 как акценты, иногда m6.
  Pulse (ровные 16-е) или gallop (3-3-2); вариацию даёт фильтр.

### Топорный 1-тактовый ломаный аккорд
- **Симптом:** лид как MIDI-упражнение по арпеджио.
- **Почему:** 1-тактовый ломаный аккорд по кругу; нет направления, пауз,
  смены регистра.
- **Вместо:** если арпеджио — 2 такта, широко и направленно (F#5→F#6), с
  возвратами и скачком. Или разреженная мелодия с паузами.

### Слишком много нот в разреженной мелодии
- **Симптом:** «разреженная» мелодия либо стена, либо исчезает.
- **Почему:** нет компенсации gain/release; нет пауз; нет длины фразы.
- **Вместо:** 1 нота, пауза, 3 ноты, пауза; 4-тактовая фраза; длиннее release
  и небольшой gain. Пауза — крючок.

### Мутация риффа каждый такт
- **Симптом:** рифф не устаивается, нет гипноза.
- **Почему:** изменения каждый такт, а не на границах 8/16.
- **Вместо:** держи ячейку 8/16 тактов; меняй одну ноту на границе; мелодию
  брейка — 4-тактовыми кусками.

### Нет динамического среза у лида
- **Симптом:** лид статичен и тонет.
- **Почему:** один cutoff на всю секцию.
- **Вместо:** медленный LFO на base + автоматика секции; для длинных нот —
  `lpdepth`/`lpsync`; delay/reverb помогают, но не заменяют движение.

## 4. Psy FX вставки

### FX каждый такт / в дропах
- **Симптом:** трек забит, FX спорят с мелодией.
- **Почему:** нет масок и места; FX как непрерывный слой.
- **Вместо:** fat low — это **слой**, бьёт каждые 4 такта с интро (3×A1, затем A0);
  laser/bubble/crunch — 1 такт из 8/16 в пустотах (интро/грув/билд/аутро), не
  в плотных дропах/лифтах. 8/16-тактовые маски и гейты таймлайна.

### Высокие тонкие «капельки» как главный FX
- **Симптом:** FX как рингтон, нет веса.
- **Почему:** высокие sine/FM-щелчки с терцией/аккордом; много нот; слишком
  часто.
- **Вместо:** bubble = 4 нейтральных щелчка, только root + m2 (F#6/G6), 1 такт
  из 16. Для веса — fat low: A1 с интро, одна нота каждые 4 такта, три удара A1, затем
  A0; срез 1800–2400 (LFO 4 такта), resonance 14–24 (LFO 8 тактов), attack,
  сильное эхо + длинный реверб, unison/drive/pan. Без m3 в bubble — становится попсово.

### Один выстрел без пространства
- **Симптом:** FX сухой и выпадает.
- **Почему:** нет pan/delay/room; нет фразы.
- **Вместо:** pan LFO/random, delay (3/8), короткая комната; 4-тактовый маск,
  чтобы это была фраза, а не случайный удар.

### Один реверб на FX / слишком много райзеров
- **Симптом:** размытые хвосты, CPU.
- **Почему:** несколько roomsize; райзеры в каждой секции.
- **Вместо:** один общий `roomsize`; райзер только в билде/брейке; reverse
  crash на входе, не везде.

## 5. Аранжировка

### Нет интро кик+бас / всё с первого такта
- **Симптом:** трек стартует забитым; нет DJ-входа.
- **Почему:** всё сразу; нет вычитания.
- **Вместо:** 16 тактов кик+бас; хэты (16–32), клэп/снейр (32–48), open hat/
  перкуссия (48–64); для брейка убирай элементы.

### Open hat дольше 64 тактов
- **Симптом:** усталость; «роллинг» перестаёт быть подъёмом.
- **Почему:** нет сброса.
- **Вместо:** сбрось open hat на брейке или убери на 8–16 тактов; верни с
  дропом.

### Статичная 4-тактовая петля
- **Симптом:** это луп, а не путешествие.
- **Почему:** нет смен 8/16; нет билда/брейка.
- **Вместо:** форма INTRO → GROOVE → LIFT → BREAK → BUILD → DROP → GROOVE 2 →
  PEAK → BREAK 2 → OUTRO; смены на 8/16; крупные — на 16/32.

### Мелодия брейка не развита
- **Симптом:** брейк — повтор 1-тактового плака; нет дуги.
- **Почему:** нет удлинения и вариации.
- **Вместо:** 1-тактовый мотив ×4 = 4-тактовый кусок; четыре куска: база /
  первая +1, третья +2 / база / первая и третья −2. 16 тактов развития без
  аккордов.

### Нет вычитания / 10 слоёв
- **Симптом:** мутно, нет воздуха и контраста.
- **Почему:** добавляешь вместо того, чтобы убирать.
- **Вместо:** если секция мутная — убери элемент; держи 2–4 акцента, а не 10
  слоёв «на всякий случай».

## 6. Микс

### Лид спрятан под пэдом/басом
- **Симптом:** мелодия есть, но её не слышно.
- **Почему:** пэд/бас слишком громкие; лид тихий.
- **Вместо:** проверка `levels`: лид не в 2 раза тише пэда; high-pass пэда,
  место для лида; delay/reverb для присутствия.

### Слишком много реверба / большой hall
- **Симптом:** всё далеко, нет панча.
- **Почему:** `room` слишком высокий; `roomsize` слишком большой.
- **Вместо:** короткая комната, низкий send; реверб на пэдах/лидах, не на
  кике/басе.

### Кик/бас дерутся за 40–80 Гц
- **Симптом:** нет веса или размазанный низ.
- **Почему:** оба в одной полосе; нет EQ-разделения.
- **Вместо:** кик и бас моно; high-pass баса ~30 Гц; notch на фундаменте кика;
  тюнинг кика в стороне от корня.

### Перекомпрессия / нет транзиентов
- **Симптом:** плоско, нет панча.
- **Почему:** тяжёлая компрессия/дисторшн на всём.
- **Вместо:** короткий кик, лёгкий drive; сайдчейн 2–4 дБ; оставляй транзиенты.

## 7. Strudel / проект

### Мини-строки в переменных без `m()`
- **Симптом:** в браузере тишина; verify ругается.
- **Почему:** транспайлер оборачивает только двойные кавычки; одинарные
  остаются строками.
- **Вместо:** каждая мини-строка через `m(...)`; вычисляемые строки тоже
  передавай в `m(...)`; без голых мини-строк в переменных.

### `.scale`, `chord()`, `voicing()` в node-проверке
- **Симптом:** `verify` падает с `not a function`; браузер может работать.
- **Почему:** node-проверка не грузит `@strudel/tonal`.
- **Вместо:** в треке — явные ноты/паттерны; `.scale` — для экспериментов;
  трек должен проходить `verify`.

### Неверные имена сэмплов / банков
- **Симптом:** тишина или предупреждение о сэмпле.
- **Почему:** `s('sbd')`, `bank('RolandTR909')`, `s('sh')` есть не в каждой
  карте.
- **Вместо:** проверяй в stock strudel.cc; грузи те же карты; держи fallback
  (`bd`, `hh`, `oh`); смотри консоль.

### Отрицательные литералы в `slider`
- **Симптом:** виджет показывает NaN; значение неверное.
- **Почему:** парсер слайдера читает литерал.
- **Вместо:** 0…N и знак в коде (`.mul(-12)`).

### Мёртвые слои / нет гейтов
- **Симптом:** слой играет, когда должен молчать; CPU зря.
- **Почему:** нет `gateOf`/`audible`; loop-only слой остаётся.
- **Вместо:** `.mask(gateOf(...))` + `.filter(audible)` на каждом слое;
  `loopLevel=pure(0)` для riser/roll/reverse.

### Нет проверок / нет stock strudel.cc
- **Симптом:** в панели работает, в реальном плеере — нет.
- **Почему:** panel-only хелперы; нет статической/живой проверки.
- **Вместо:** `npm run verify`, `gains`, `cpu`, `levels`, `live`; проверь в
  stock strudel.cc; коммит до экспериментов.

## 8. Перед коммитом — быстрый чеклист

- [ ] Один корень; без прогрессии/обыгрывания аккордов.
- [ ] 12 нот баса; sub+top; sustain 0; зазор; моно; сайдчейн.
- [ ] Acid: низкий base + глубокая огибающая; Q 0–4; динамический срез.
- [ ] Рифф повторяет одну ноту; m2/m3; иногда m6; pulse или gallop.
- [ ] Мелодия брейка 4 куска; лифт разреженный, с паузами.
- [ ] Fat low каждые 4 такта с интро, 3×A1 затем A0; laser/bubble/crunch
  редкие; bubble только m2; не в дропах.
- [ ] 16 тактов интро; слои; брейк/билд; сброс open hat.
- [ ] Один roomsize ≤10; лид не спрятан; низ моно.
- [ ] `verify` 0; `gains` тихо на нулях; `cpu` <150/с; `levels` в норме.
- [ ] Проверено в stock strudel.cc; каталог/доки обновлены.
