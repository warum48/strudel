# Dub Techno — рабочий плейбук

Выжимка из ресёрча и треков `techno/16-minimal-dub`, `techno/17-halfstep-dub`
и `techno/17-halfstep-dub-v2`. Цель — чтобы следующий даб-техно трек можно было
собрать без повторного поиска.

## 1. Два характера

| | **Классический / Basic Channel** | **Burial-leaning halfstep** |
|---|---|---|
| Темп | 120–125 BPM (Tunary: до 130) | 104 BPM |
| Бочка | 4/4, глухая, мягкая | 1 + пикап или 1 + 3.5 |
| Снейр | нет (или редкий rim) | на 3, halfstep |
| Хэты | оффбит, мягкие, в дилее | шуршащие 16-е со свингом |
| Гармония | 1–2 аккорда, 9/11, bII | Dm9 → Bbmaj9, вокальный пэд |
| Бас | саб ≤80 + dub-бас ≤80 | саб ≤80 + growl (осознанное исключение) |
| Главный звук | короткий стаб в длинном дилее | стаб + пэд + Moog/эхо |
| Референс в репо | `techno/16-minimal-dub.js` | `techno/17-halfstep-dub.js`, `-v2` |

## 2. Что делает звук «дабовым»

1. **Меньше событий, больше пространства.** Кик, саб, один стаб, редкий rim,
   мягкие хэты — этого достаточно. Пустота и шум — часть грува.
2. **Delay/reverb — инструмент, а не украшение.** Сухой стаб короткий;
   характер делает фильтрованный хвост. Feedback ~0.40–0.65, повторы темнее
   сухого сигнала, реверб после дилея.
3. **Медленное движение.** Меняются срез, feedback, level на 8/16/32 такта.
   Новые секции, райзеры и дропы не нужны.
4. **Низ — центр.** Саб ≤80 Гц; кик глухой (lpf ~250–300); верх срезан.
   Никакого bright-мастера и «воздуха» выше 8–10 кГц.
5. **Шум как тело.** Винил/crackle, розовый воздух, wind/field recordings.
   Без них стаб звучит как MIDI.
6. **Гармония висит.** Am9 → Bbmaj9 (bII) или Dm9 → Bbmaj9. Никакой
   1–2–4–5, доминантовых разрешений и «красивых» мелодий.

## 3. Аранжировка

- **Один цикл = один такт 4/4.** `setcpm(BPM / 4)`.
- Фразы — 8 тактов (или 16 для очень медленных пэдов). Маркер `@roots` обязателен.
- 4+4 такта — хороший минимальный ход: 4 такта одного аккорда, 4 такта bII.
- **Modes** меняют только текстуру (хэты/rim/click/шейкер), не форму:
  `DUB → STRIP → PRESSURE → CLICK`.
- **Harmony** — защёлка на 8 тактов: `WARM` (низкий вокальный/пильный пэд) /
  `AIR` (высокий открытый призрак).
- **Scenes** (`// @scenes`) — Intro/Theme для быстрого переключения микса.
- Старт: только атмосфера. Кик/саб/стаб/пэд поднимаются руками.

## 4. Звуковой дизайн

### Кик
- `s("bd*4")`, `.lpf(260)`, лёгкий `.shape(0.45)`, короткий decay.
- Никакого клика, дисторшна и «щелчка» сверху. Это сердце, а не удар.
- В halfstep: кик на 1, иногда пикап на последнюю 16-ю.

### Саб и dub-бас
- **Правило проекта: срез ≤80 Гц.** В слайдере max = 80, выше не поднять.
- Саб — `s("sine")`, оффбит-пульс (`~ x ~ ~ ~ x ~ ~`), не на долю с киком.
- Dub-бас — `s("triangle")`, фраза с паузами и контрапунктом: квинта, b7,
  11-я, педаль. Не «тоника–терция–квинта».
- В классическом дабе бас может быть копией хвоста кика, отфильтрованной
  до саба. В Strudel проще отдельный синус.

### Стаб
- Короткий аккорд (3–5 нот) на «и» доли, не на каждую долю.
- `s("sawtooth").unison(2).detune(...)`, lpf 900–1200, lpq 3–5.
- `.decay(0.25–0.4).sustain(0)`, затем `.delay(send).delaytime(0.375)`
  (пунктирная четверть при 120 BPM = 0.75 с), `.delayfeedback(0.55)`,
  `.room(...)`.
- Сухой стаб должен быть слышен громче первого эха. Иначе получается
  «реверб-каша», а не даб.

### Пэд
- Не лид и не аккомпанемент. Долгая атака (4–6 с), release 12–18 с,
  низкий срез, chorus, большой тёмный реверб.
- `WARM`: `sawtooth` + `partials`, unison 2, detune 0.06–0.09.
- `AIR`: `triangle` + `partials`, unison 3, detune 0.12–0.15, выше и прозрачнее.
- Открытые квинты/9-е без терций — хороший второй слой.

### Хэты, rim, click
- Хэты — оффбит, мягкие, lpf 5–6 кГц, в дилее на 30–40 %.
- Rim — сухой деревянный тик; в STRIP заменяет хэты.
- Click — редкие цифровые точки, только в STRIP/CLICK; выше 2 кГц.
- Снейр на 2/4 не ставим: это уже не даб.

### Текстуры
- `crackle` — винил/хайс; `pink` — воздух; `wind` из Dirt-Samples —
  поле/пейзаж. Всё очень тихо, с фильтрами и медленной панорамой.
- Шум не «эффект», а тело трека.

## 5. Гармония без попсы

- **Am9**: a c e g b. **Bbmaj9**: bb d f a c. Пара bII + 9-я — сочный
  диссонанс без доминанты.
- **Dm9**: d f a c e. **Bbmaj9**: bb d f a c. Тот же bVI-сдвиг для Burial.
- Избегай пары **e–bb** (тритон) в одном аккорде/такте. В Am9 есть e, в
  Bbmaj9 — bb; не ставь их одновременно в басу и стабе.
- Линии в басу/стабе не должны идти «по тонам аккорда» вверх-вниз. Паузы,
  педаль, квинта, 11-я — лучше.
- Никаких 303-обыгрываний аккордов. 303 — только атональный риф/арпеджио
  с 1–2 нотами на аккорд, если он вообще нужен.

## 6. Микс

- Мастер тёмный: без air boost, без яркого верха, без over-compression.
- Дилей и реверб — на отдельных инструментах, не на мастере.
- Бас ≤80; кик глухой; стаб и пэд не должны забивать низ.
- Никакого sidechain-пумпа, райзеров, white-noise билдов, snare-роллов
  и «дропов». Это EDM-язык, не даб.
- Если партию можно убрать без потери идентичности — убери.

## 8. Чек-лист следующего трека

- [ ] Выбрать характер: 120 BPM classic / 104 BPM halfstep.
- [ ] Выбрать 1–2 аккорда: Am9/Bbmaj9 или Dm9/Bbmaj9; `@roots`.
- [ ] Собрать дерево `instruments`: atmos / drums / bass / chords / fx.
- [ ] Кик глухой, саб ≤80, dub-бас с паузами.
- [ ] Один стаб на оффбит + delay 0.375 / feedback 0.55 / фильтр.
- [ ] Пэд WARM/AIR, без мелодии.
- [ ] Шум/хайс/поле; старт в тишине.
- [ ] Modes + harmony latch 8; при желании `@scenes`.
- [ ] `verify`, `tension`, `modes`, `latch`, `gains`, `doubles`, `cpu`, `live`.
- [ ] Проверить, что трек живёт 2 минуты без новых секций.

## 9. Khmer dub (`techno/18-khmer-dub.js`)

Дабовый низ + кхмерский верх. 122 BPM, Fm9 → Abmaj9 → Dbmaj9 → Gbmaj9
(четыре аккорда по два такта, 9-е), другие ноты, чем в 16/17. Пэд
короткий, стаб тёмный, есть Moog-линия и тихое арпеджио.

- **Дабовый набор:** kick / hat / rim / click / shaker, sub / dub bass,
  pad warm/air, stab, organ, skank, horns, hiss / air / field, dub delay
  + reverb. Саб ≤80, кик 270, стаб в дилее, никаких мелодий и дропов.
- **18 кхмерских драмов:** skor high/fill, sampho low/high/ghost/rim,
  chhing closed/open/roll. 18 каналов в MIXER (vol / cut / clip), один
  перкуссионный автобус в коде.
- **Все 18 через общий delay + reverb:** `percEcho` 0…0.8, `percVerb` 0…1,
  `verb` 0…1, `verbSize` 1…20. Это дешевле 18 отдельных хвостов.
- **Таймлайн:** нативная читаемая `const TIMELINE = [...]` — обычный массив
  объектов (single quotes), 5 секций / 64 такта, 11 множителей на секцию,
  `tlCurve` + `arrange`. Играется в обычном
  Strudel; слайдеры hot, правки таблицы — по Ctrl+Enter или APPLY. Панель
  рисует секции, target-множители и playhead. LOOP возвращает playhead на 0;
  при выключенном LOOP трек останавливается на конце. В MIXER у каждого канала
  есть M/S (mute/solo), код они не меняют, и G (групповой mute, цвет по
  группе). Для 18 группа задаётся полем `mute:` в дереве, поэтому верхний
  ряд `@mutes` скрыт. Секции идут подряд: длина одной
  сдвигает `at` следующих; порядок — стрелками ↑/↓. Клик по линейке — seek.
  Reverb/delay не автоматизируются, чтобы не рвать хвосты.
- **Mutes:** skor / sampho / chhing. `mode` — только
  верх, `harmony` — warm/air с защёлкой 8 тактов.
- **Проверки:** 19 дорожек / 111 ударов на INTRO / 149 слайдеров, tension
  clean, cpu 0 на INTRO и 15/такт (8/с) в DUB, doubles без наложений, live ок.
