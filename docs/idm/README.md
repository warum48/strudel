# IDM — библиотека приёмов

IDM в этом проекте — способ собирать ритм из микро-событий: щелчков,
обрывков, гранул, 8-битных писков и коротких кислотных нот. Мелодия
здесь — не тема, а ещё один тембр; грув — не сетка, а последовательность
решений. Именно так и получается «умная электроника»: сложность в
секвенции и отборе, а не в количестве слоёв.

Трек-пример: `tracks/idm/01-splinter.js` (136 BPM, 33 дорожки, 193 слайдера,
8 переключателей, 6 пэдов), `tracks/idm/02-splinter-v2.js` — та же
палитра в форме на 96 тактов (SONG/LOOP/HOLD, 2 свитча, без пэдов и
панельных хаков) и `tracks/idm/03-splinter-v3.js` — 144 такта, 4 свитча,
VOICE LAB с автоматизацией голоса/грануляра, больше глитча и кислоты;
`run` там — синкопированный 16-й рифф с октавным слайдером.

---

## 1. Характер

| Признак | Как это звучит | Что НЕ делать |
|---|---|---|
| Глитч | обрывки, стуттеры, рвань между долями | не превращать в ровный брейккор |
| Грануляр | облако из коротких кусков, позиция и окно едут | не делать «реверб-пэд» из гранул |
| Микро-события | клики, тики, писки, короткие 8-битные ноты | не заполнять все 16-е |
| 8 бит | pulse/square, crush, быстрые арпеджио | не играть «весёлую» мелодию |
| Эйсид | 303 с выборочным glide, широкие интервалы | не обыгрывать аккорды 16-ми |
| Бас | саб ≤80 + шершавая середина + FM-резина | не путать growl с сабом |
| Пространство | мало реверба, короткие комнаты, дилей и панорама | не топить всё в большом hall |

Главный принцип: **сложность — в секвенции, а не в количестве слоёв**.
Форумный консенсус (Elektronauts, IDMForums, Renoise) сходится в одном:
слушателю кажется, что играет десять инструментов, а на деле играет
три, но каждый удар вылизан. Рандом — специя, а не несущая конструкция.

## 2. Из чего собран трек

```
atmos   — винил, воздух, wind
drums   — kick, snare, hats, open, clicks, glitch, squeaks, roll/cut/burst/drop
bass    — sub ≤80, growl (mid), FM rubber
acid    — line (sparse), run (octave up), scream (shape+crush)
grain   — cloud, scan, freeze, edit; источник padlong/space/wind/noise2
bits    — lead (pulse), arp (square), blips (noise)
vox     — numbers (spoken digits), dry/chop/pitch
chords  — dark pad (tritone dyads), ghost pad (fifths+9), stab
fx      — delay, small reverb
```

Гранулярный источник меняется: в `grainSrc=auto` банк
`padlong → space → wind → noise2` идёт по 4 такта. `pitch` у cloud/scan/
freeze/edit — от −24 до +12 полутонов, то есть до двух октав вниз.

Ритм мутирует двумя макросами: `mutate` (0…1) оставляет случайные
призраки снейра/хэта/глитча, `fill` (0…1) вводит 32-й филл по снейру
на последнюю долю. Режимы 4–7 (`skitter`, `shuffle`, `poly`, `fracture`)
включают все барабанные слои, а не только кик.

### Переключатели

| Ручка | Значения | Что делает |
|---|---|---|
| `scene` | intro · build · main · break · outro | аранжировка: слои входят и уходят |
| `mode` | glitch · grain · acid · strip · skitter · shuffle · poly · fracture | рисунок барабанов; 4–7 включают все слои |
| `grainMode` | off · cloud · scan · edit | какой гранулярный слой звучит |
| `grainSrc` | auto · padlong · space · wind · noise2 | источник грануляра: auto меняет банк раз в 4 такта |
| `bitMode` | clean · crush · coarse · both | глубина бит-круша у 8-битных слоёв |
| `acidMode` | off · sparse · run · scream | 303: выкл / разрежено / октавой выше / крик |
| `voxMode` | off · dry · chop · pitch | голос `numbers`: выкл / сухо / рубить / питчить |
| `harmony` | dark · ghost | тритоновые пары или квинты с 9-й; защёлка на 8 тактов |

### Пэды (momentary, клавиши 1–6)

| Пэд | Что делает |
|---|---|
| `padRoll` | 32-е из glitch: держишь — ролл |
| `padCut` | рваный стуттер с дырами |
| `padFreeze` | замораживает гранулярное облако в текущей позиции |
| `padBurst` | шумовой промышленный удар |
| `padAcid` | добавляет 303-крик поверх линии |
| `padDrop` | короткий саб-дроп |

Пэд — это слайдер 0/1, который панель пишет на время нажатия. В треке он
обязан быть гейтом: `.gain(instrument.vol.mul(padX))` и `.filter(audible)`.

### Сцены

`// @scenes` даёт две кнопки: `INTRO` (атмосфера, облако, клики) и `THEME`
(полный грув с бочкой, басом, кислотой и 8-битным лидом; пресет из
`dumps/idm-01-splinter-2026-11-15-20-13-18.json` — 193 ключа). Экспорт/
импорт JSON — в панели.

## 3. Как играть

1. `npm run web` → `tracks/idm/01-splinter.js`.
2. Начни с `INTRO`: `scene 0`, `grainMode 1`, `verb 0.18`.
3. `THEME` или вручную: `scene 2`, `mode 1` (grain), `grainSrc 2` (space),
   `bitMode 2` (coarse), `acidMode 1`, `voxMode 2` (chop).
4. Держи `1` (roll) на последнем такте фразы, отпусти.
5. `padFreeze` (3) — один-два такта, чтобы облако «зависло».
6. `padCut` (2) — на сломе, не постоянно.
7. `grainMode 2` (scan) — когда облако должно поехать.
8. `acidMode 3` (scream) — коротко, на кульминации.
9. `mode 3` (strip) — снять барабаны, оставить бас и микро-события.
10. `padDrop` (6) — только на входе в новую секцию.

Правило: **реже — лучше**. Один пэд за фразу, один переключатель между
секциями. Если кажется, что мало — сначала убери слой.

## 5. Гейты

Новый IDM-трек считается готовым, когда проходят:

`verify`, `tension`, `modes`, `latch`, `gains`, `doubles`, `cpu`, `live`.

Для `01-splinter`:

- `verify` — 33 дорожки, 130 ударов за такт, 193 слайдера, 0 ошибок.
- `tension` — трения нет; 140 намеренных тритонов в якорных фразах (`@dark`).
- `modes` — 8 сеток: кик 16/8/16/4/28/20/24/40,
  снейр 12/4/8/0/20/8/16/32.
- `latch` — гармония переключается на такте 8, не на 4.
- `gains` — при всех нулях тихо.
- `doubles` — наложений нет.
- `cpu` — 25–28 worklet/такт = 14–16/с.
- `live` — eval ок, паттерн играет, слайдер синхронизирован.
