## 6. How to refresh / fetch more

```bash
python3 docs/breakcore/_tools/scrape_discourse.py
```

The script:
- fetches Discourse JSON (`/t/<id>.json?page=N`);
- requires `certifi` and a browser User-Agent (otherwise SSL/403);
- writes `threads/<host>-<id>-<slug>.md`;
- the topic list is `TOPICS` inside the script; add `(host, id, max_pages)`.

`max_pages=None` = fetch everything; a number = cap (for gigantic threads).
