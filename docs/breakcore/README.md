## 0. Что такое брейккор (рабочее определение)

- **Барабаны — главный элемент, остальное — фон.** «Electronically composed drum solos
  with the drum solos being the main element of a track with other sounds being a
  backdrop» — bfk `[6643#1]`.
- **Жанр определяется брейкбитом, а не темпом.** Диапазон в тредах: 150–360 BPM
  `[26084#3]`; встречаются треки на 90 BPM, где «брейккорность» даёт не скорость,
  а микротайминг `[5102#18]`.
- **Это не «много нот».** Ключевое — нарезка, гейтирование и грув; «есть много
  тяжёлого брейккора на чистых битах» `[17702#3]`.
- **Наследие:** jungle/DnB (Amen, Think), hardcore/gabber (кик, агрессия),
  IDM (микроредактирование, генеративность), noise/industrial (текстура) `[26084#3]`.

Рабочая формула: **один брейк → мелкая нарезка → жёсткий микротайминг →
2–3 слоя → один дисторшн-тракт → саб → мутация каждые 4 такта**.

## 1. Три школы нарезки (выбери одну как основу)

### A. Rinse / note-off (моно-колонка) — «канон»
Один трек на весь брейк, все хвосты обрезаются **note-off перед следующим
сэмплом**, DSP один на всю колонку.

- «always put a note-off before the next sample and usually keep a break rinse
  limited to one column» `[29927#1]`.
- Тишина получается «миллисекунды или меньше» и делит трек на такт идеально `[29927#1]`.
- Удаление note-off'ов = «muddy and muffled» `[18985#46]`.
- Масштаб: 8 LPB при 400 BPM — «прецизионно для деталей» `[29927#14]`.
- Плюс: цельный характер брейка. Минус: нет поштучного контроля.

### B. 09xx / offset-mashing — «живой грув»
Не резать, а триггерить *позиции внутри сэмпла* (`09xx`), сохраняя динамику живой игры.

- «0922 = hard snare, 0948 = soft kick, 0972 = ride cymbal» `[29927#12]`.
- Случайные значения часто звучат лучше расчётных: «wild rafting» vs
  «controlled paddling» `[29927#13]`.
- Длинный брейк делить на 2+ ровные части и ссылаться на них **в одной колонке**,
  чтобы осталось моно `[29927#18]`.
- `900–9FF` меняет позицию, сохраняя исходную высоту `[18985#50]`.
- Требует знания карты сэмпла (или бумажной шпаргалки).

### C. Per-hit stems — «микшерский» подход
Каждый элемент на своём треке: `bd=Track01, sn=Track02, chh=Track03`, сумма в один
сенд для компрессии/EQ/фильтра `[29927#19]`.

- Максимальный контроль: «pitch slide this kick while I 0Exx that snare» `[29927#28]`.
- Риск: «именно поэтому большинство самозваного брейккора звучит шумно и с
  неамбициозными паттернами» `[29927#10]` — если просто разложить лупы по трекам
  без нарезки, получается каша.
- Противовес: atomly считает, что брейки **почти никогда не надо лейерить** и
  вешать эффекты «если только ты не хочешь, чтобы брейк звучал именно так» `[34022#32]`.

**Практика:** A для основы (характер), B для живости/филов, C точечно для кика/снейра.

## 2. Канонический рецепт (MVP за один вечер)

1. **Темп.** 170–180 BPM как рабочая точка; 5/8 или смена метра — опция, не
   обязанность `[6643#49]`. Помни: у каждого брейка есть «потолок» темпа —
   «there is an upper bound of tempo that any given break wants to be at»
   `[226901]`.
2. **Брейк.** Amen / Think / Hot Pants / Apache / Funky Drummer `[175570, 173927]`.
   Amen-оригинал ~136 BPM `[29927#32]`.
3. **Нарезка.** 8–16 слайсов; резать по 1/4 и 1/8, **не по 16-м** —
   «You loose all the groove if you chop too tight» `[226901]`. Типичный
   продвинутый минимум — 3–5 маркеров `[175570]`.
4. **Ре-секвенс.** Новый порядок; пере-питч копий ±1–2 полутона; роллы в конце фраз.
5. **Note-off / гейт.** Обрезать каждый хит перед следующим `[29927#1]`;
   альтернатива — `0403→0407→04FF` гейт `[34022#24]` или volume-slide `07xx` `[29927#18]`.
6. **Снейр-вариация.** 3–5 разных снейров, разная velocity; ghost-снейр =
   тихий удар в «пустом» месте `[18985#66]`.
7. **Слои.** Кик/снейр/хэт отдельно, сумма → один дисторшн-тракт `[29927#19]`.
   Снейр: 3–5 сэмплов `[26084#17]`.
8. **Грязь.** Дисторшн/бит-круш на суммарный брейк-бас, LoFi (снижение SR + bit
   depth) `[173811]`, короткие делэи/комб-фильтр на отдельные хиты `[173927]`.
9. **Низ.** Саб отдельно, моно, sidechain в кик; срезать низ у нарезанных
   брейков, иначе «muddy garbage» `[173927]`.
10. **Структура.** Каждые 4 такта — новое ритмическое/мелодическое зерно `[44354#6]`;
    барабаны делятся на «ритм-гитару» и «лид-гитару» `[6643#47]`.
11. **Разрежение.** 2–3 одновременных элемента; одна 16-я последовательность
    за раз `[173927]`.
12. **Финал.** Свести, отслушать на «пустоту»: если всё время плотно — убрать слой.

## 3. Семь пунктов, которые нельзя нарушать

1. **Note-off / гейт на каждом хвосте** — иначе брейк «muddy and muffled» `[18985#46]`.
2. **Не варпить чопы под сетку** — «Warp is the groove killer» `[175570]`.
3. **Не резать по каждой ноте** — «over-chopping» = шум, а не музыка `[44354#1, 226901]`.
4. **Разрежение:** «only one thing is ever playing at a time» / 2–3 звука `[173927]`.
5. **Один 16-й рисунок за раз**; второй 16-й слой = каша `[173927]`.
6. **Снейр должен дышать:** 3–5 разных сэмплов + velocity, а не один клон `[18985#66, 26084#17]`.
7. **Структура важнее плотности:** 4-тактовые мутации и контраст (просто → сложно) `[44354#6]`.

## 4. Что почти всегда убивает трек

- **Пере-чоппинг** до состояния «spastic noise» `[44354#1]`.
- **18 паттернов из 3 вариаций** `[6643#15]` — видимость работы вместо развития.
- **Рандомайзеры как основа** — «stay away from randomizers!!!» `[173927]`,
  «Nothing should be random. That's the 'Intelligent' part of IDM» `[173927]`.
- **Варп / тайм-стретч чопов** → грув умирает `[175570]`.
- **Копирование Venetian Snares/Aphex** — «don't try to be like Venetian Snares.
  Find your own thing» `[21030#10]`.
- **Перекомпрессия верха при дисторшне** → мелодия перестаёт садиться `[17702#5]`.
- **Микроредакционный перфекционизм** — «micro editing spiral without getting
  anything done» `[2328#20]`.

Подробно — `07-pitfalls.md`.

## 7. Чеклист приёмки (перед тем как сказать «готово»)

- [ ] Брейк нарезан крупно (1/4–1/8), не по каждой ноте.
- [ ] У каждого хита есть обрезка (note-off / короткий amp-env / гейт).
- [ ] Ни один чоп не варплен под сетку.
- [ ] Снейр — минимум 3 разных сэмпла или 3 velocity-уровня.
- [ ] Одновременно звучит ≤3 элемента; нет двух конкурирующих 16-х.
- [ ] Есть один суммарный дисторшн/бит-круш тракт на брейк.
- [ ] Саб моно, срезан низ у нарезанных брейков.
- [ ] Каждые 4 такта — изменение (новый хит, ролл, смена слоя).
- [ ] Есть участок «просто» (чистый кик/снейр), чтобы сложность читалась.
- [ ] Нет прямой имитации конкретного артиста.

## 8. Открытые разногласия (не выдумывай консенсус)

- **Семантика питч-команд в Renoise:** `xx10` = полутон (Rex) vs `0180` = октава
  (Kosta) — верить Rex `[34022#22–23]`.
- **Vsnares-настройки:** speed 3 / TPB 1 vs TPB 3 — чтение видео позже отозвано
  `[18985#15–17]`.
- **Лейеринг брейков:** «closest friend» `[26084#15]` vs «almost never layer»
  `[34022#32]`.
- **Генеративность:** инструмент для вариаций `[173927]` vs основа трека `[2328#10]`.
- **LPB/BPM:** 8 LPB/400 vs 16 LPB/200 — звучит одинаково, разница визуальная `[29927#21, #24]`.
