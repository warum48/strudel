Well, here we go!

I’m hoping we can start off a new competition where we produce Drum and Bass!

This one is going to be based on Animation.  Pick a theme, or a song from something Animated.  Something from your childhood or something from last week.  It can be Disney, or Studio Trigger, or something from PBS.

I’m hoping for a good turn out, and since this is new, there are very few rules, if any at all.

The next battle will be more restrictive with suggestions from the winner.

Here are the official rules…

Try to stay on theme.

No Caillou.  That dude sucks.

But this is truly a free for all, so if you make something, send it in to me via private message. (Even if you do Caillou…)

The deadline is the first of the year (Janurary 1, 2023).  So you can try out all the new synths that you got for the holidays!

On the first, send in whatever you got, and I will put it up on a Soundcloud page that I upgraded so I can post unlimited tracks.

I’m really into this just to hear some great music, so this first battle is going to be real loose, and the following ones will have more limitations, for sure.

But for the first one, my fellow Elektonauts, it’s open season.

I’m not sure this is allowed, but I want to give the winner after we vote a gift card to Starbucks.  Nothing big, just $5, but enough to christen the first battle.

Let me know if you have any questions!
