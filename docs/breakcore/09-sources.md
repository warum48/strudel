## 6. Как обновить/дозагрузить

```bash
python3 docs/breakcore/_tools/scrape_discourse.py
```

Скрипт:
- качает Discourse JSON (`/t/<id>.json?page=N`);
- требует `certifi` и браузерный User-Agent (иначе SSL/403);
- пишет `threads/<host>-<id>-<slug>.md`;
- список тем — в `TOPICS` внутри скрипта; добавь `(host, id, max_pages)`.

`max_pages=None` = качать всё; число = ограничить (для гигантских тредов).

## 7. Ограничения корпуса

- Всё на английском; переводы и цитаты — авторские.
- Форматирование в `threads/` плоское: картинки `[image]`, ссылки `text (url)`.
- Не все посты гигантских тредов скачаны (см. §2).
- Два внешних URL (IDMForums `386`, `6643`) были найдены через поиск-метаданные,
  но позже успешно скачаны — сомнение снято.
- Треды старые (2010–2026): плагины и ссылки могли умереть, техники — нет.
