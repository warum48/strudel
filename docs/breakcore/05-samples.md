## 3. Что есть в этом репозитории

Два проверенных сэмпл-мапа, уже подключённых в `tracks/dnb/*`:

```js
samples('github:yaxu/clean-breaks/main')
// amen  — полный Amen Brother
// think — Think break (Lyn Collins)
// apache — Apache (Incredible Bongo Band)

samples('github:tidalcycles/Dirt-Samples')
// amencutup — 32 нарезанных куска Amen
// jungle    — готовый jungle-кит (kick/snare/hat/ride/perc)
// jungbass  — глубокие сабы (mega_jungasubdown)
// hardcore  — кик/снейр для габбер-слоя
// industrial, glitch, noise2, dist — текстуры
// hoover    — рейв-хувер
```

Это ровно тот набор, который нужен брейккору: один полный брейк + нарезанная
версия + кик/снейр + саб + текстуры.

## 4. Подготовка сэмплов

### Метаданные в имени файла
- `file_bpm160.wav` — BPM в имени, авто-синк `[60185]`.
- `file_beats4_bpm160.wav` — число долей в имени, чтобы слайсы попадали точно `[60185]`.

### Подготовка брейка
1. Привести к целевому темпу **без варпа**, если возможно: пере-питч `[175570]`.
2. Проверить «потолок темпа» брейка: «There is an upper bound of tempo that any
   given break 'wants' to be at» `[226901]`.
3. Обрезать тишину в начале/конце, чтобы слайс 0 = первый удар.
4. Сохранить версию «сырую» и версию «обработанную» (tape stop, flanger,
   растянутую) — обработанные варианты добавляются в тот же источник как
   дополнительные слайсы `[175570]`.

### Пакетная нарезка
- Reaper: импорт многих файлов → batch export слайсов в WAV `[173927]`.
- Wavelab: batch-обработка `[173927]`.
- Koala / Blackbox: auto-chop по транзиентам, потом правка `[175570]`.
- `makebreakbeat` (norns): onset detection с минимальной дистанцией 1/16, sox
  splicing с leeway + сравнением формы волны + crossfade `[53301]`.

## 5. Стем-сепарация

В корпусе **не обсуждается** — единственное упоминание терминологии:
«Clips is just the Ableton term for stem» `[173927]`. Не приписывай тредам
техники, которых там нет.

Практика (вне корпуса, общеизвестная): выделить барабаны из готового трека для
референса, но для продакшена использовать оригинальные брейки.

## 6. Сэмплы, которых не хватает

Для брейккора, помимо брейков:
- **снейры** — минимум 3–5 разных, разная velocity `[26084#17]`;
- **хэты/ride** — для якоря 1/8 `[173927]`;
- **кик** — короткий, «snappy» `[44354#2]`;
- **габбер-кик** — как акцент `[26084#3]`;
- **саб** — моно, глубокий;
- **текстуры** — шум, металл, поле, винил-треск;
- **вокал/речь** — питч-шифт, короткий реверб;
- **оркестровые/кинематографичные удары** — для контраста.

## 7. Чек-лист сэмплов

- [ ] Есть минимум 1 полный брейк и его нарезанная версия.
- [ ] Есть 3–5 разных снейров.
- [ ] Есть отдельный кик и отдельный саб.
- [ ] Есть 2–3 текстуры (шум/металл/грязь).
- [ ] Имена файлов содержат BPM/доли, если инструмент это использует.
- [ ] Обработанные варианты брейка сохранены как отдельные сэмплы.
- [ ] Лицензии royalty-free или собственная запись.
