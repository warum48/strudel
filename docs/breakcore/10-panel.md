# 10 · Как играть трек в панели

`npm run web` → http://127.0.0.1:8080/ → выбери `breakcore/01-rinse.js`.
Панель строится из самого трека: ничего не зашито в интерфейс.

---

## 1. Что где

| Блок | Что в нём |
|---|---|
| **Mixer** (левый столбец) | только `vol` каждого инструмента |
| **Tone** (средний) | все остальные ручки: группа → инструмент, обе ступени сворачиваются |
| **Global** | `verb` + мастер-громкость панели |
| **Switches** | `mode`, `breakSel`, `slice`, `grit` |
| **Pads** | `padFill`, `padRoll`, `padChop`, `padCut` — «держишь — играет» |
| **Editor** (справа) | тот же код; `Ctrl+Enter` — запуск, `Ctrl+.` — стоп |

---

## 2. Переключатели

| Ручка | Значения | Что слышно |
|---|---|---|
| `mode` | 0 intro · 1 groove · 2 solo · 3 return · 4 outro | 0 — кик/брейк/хэты, без снейра; 2 — только барабаны и брейк, дрон/шум уходят; 4 — снятие слоёв |
| `breakSel` | 0 amen · 1 think · 2 apache · 3 amencutup | меняет источник брейка; `amencutup` — уже нарезанные 32 куска |
| `slice` | 0 sparse · 1 straight · 2 broken · 3 stutter · 4 micro | рисунок из коротких 16-х фрагментов; питч брейка не меняется |
| `grit` | 0 clean · 1 crush · 2 shape · 3 both | `crush` = бит-круш, `shape` = вейвшейпер на бочке |

Правило из тредов: **реже — лучше**. Начинай с `slice=2` (×8) и `grit=1`.

### У `02-stems-hardcore.js` набор другой

| Ручка | Значения | Что делает |
|---|---|---|
| `scene` | intro · build · main · break · outro | аранжировка: слои входят/уходят по секциям |
| `mode` | ritual · stomp · roll · half · collapse | рисунок кика/снейра |
| `kick` | clean · dist · hard | **состав кика**, а не громкость: `clean` выключает wet-слой; `dist`/`hard` добавляют сатурированную полосу |
| `char` | kick1 · kick2 | выбор готового хардкорового кика (`hardcore:4/5`) |
| `perc` | dry · metal | металлический ring на «и» |

В Tone у кика есть `pitch` (полутоны, по умолчанию −4) и `drive` (лёгкая склейка wet-слоя):
сначала драйв, потом обычная громкость. `Kick extra` — третий, синтезированный кик;
по умолчанию 0, поднимается фейдером, если нужен ещё один характер.

Пэды те же (1–4): `fill`, `roll`, `stab`, `cut`.

В Tone у `Bass line` и `Acid 303` есть своя ручка `pace` (`.slow(n)`):
1 = 8-е, 2 = 4-е, 4 = половинные. У кислоты гейт glide замедляется тем же n.

---

## 3. Пэды (momentary)

Пэд — это слайдер 0/1, который панель пишет на время нажатия:

- **pointerdown / клавиша 1–4** → значение 1, кнопка подсвечивается;
- **pointerup / keyup / уход мыши** → 0.

В треке пэд гейтит одно-тактовый слой, поэтому:

- **держишь** — филл/ролл/чоп играет и повторяется;
- **отпустил** — слой исчез, ничего не «залипло».

| Пэд | Клавиша | Что делает |
|---|---|---|
| `padFill` | 1 | снейр-раш 16-ми на такт, с нарастанием |
| `padRoll` | 2 | снейр 32-ми (8 восьмых × ply 4) |
| `padChop` | 3 | брейк 32-мя кусками |
| `padCut` | 4 | гейт-стуттер: 8 кусков, половина вырезана |

Клавиши не срабатывают, пока фокус в редакторе — там цифры печатаются как обычно.

---

## 4. Как играть сет

1. `mode=0` (intro), `slice=2`, `grit=1` — дать брейку и кику установиться.
2. `mode=1` (groove). На последнем такте 4-тактовой фразы — **1** (fill).
3. Держи **2** (roll) один такт, отпусти; через 4 такта — **3** (chop).
4. `mode=2` (solo) — дрон и шум уходят, остаются барабаны. Здесь играют только пэды.
5. `mode=3` (return) — вернуть фон и альтернативный брейк.
6. `mode=4` (outro) — снять слои, оставить кик и брейк для сведения.
7. `breakSel` меняй между секциями, а не внутри фразы: брейк должен успеть прочитаться.

---

## 5. Контракт панели (если добавляешь свои ручки)

- Дерево `instruments` → микшер/Tone. `vol` идёт в левый столбец.
- Верхнеуровневый `slider(x, 0, max, 1)` → кнопки-переключатели.
  Подписи — из строки `// @switches mode=a,b,c`.
- Строка `// @pads padFill,padRoll` помечает верхнеуровневые слайдеры как
  momentary: панель исключает их из switches и рисует пэды.
- Имя пэда = имя переменной (`const padFill = slider(0,0,1,1)`).
- В треке пэд обязан быть гейтом: `.gain(instrument.vol.mul(padX))`
  и `.filter(audible)` в конце дорожки.
- MIDI нет: только мышь и клавиши 1–4.
