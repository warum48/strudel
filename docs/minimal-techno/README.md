# Minimal techno — плейбук

Не «техно без всего», а техно, где почти ничего не меняется — и от этого
меняется всё. Материал: кик, бас, редкие перкуссионные точки, один дрон/пэд,
короткий стаб или блайп. Развитие — в фильтрах, плотности и микросдвигах,
а не в мелодии.

Наш трек: `tracks/minimal-techno/01-hollow-form.js` — 128 BPM, A-модальность
(A + E, редкий Bb), 128 тактов, 14 дорожек, свитч `mode`. **Без обычного пэда**:
вступление — металлическая текстура + шум + винил; низ — sine-дрон, а не наш
«пэд из трека в трек».

## 1. Звук

| Признак | Как делаем |
|---|---|
| Темп | 125–130 BPM (Hawtin: 128 — «идеальный»); берём 128 |
| Размер | 4/4, four-on-the-floor, ровный пульс |
| Гармония | модальная, без функциональных кадансов; один центр (A) |
| Ритм | кик, редкие хэты/rim/clap; микро-сдвиги, не «брейк» |
| Бас | саб ≤80 + редкий mid-pulse (не мелодия) |
| Текстура | шум/воздух, короткий стаб, высокий блайп |
| Развитие | медленные срезы, включение/выключение слоёв, density |

Минимал-техно любят **середину** и пустоту: не топить всё в сабе и ревере,
оставлять место между ударами.

## 2. Ритм

- Сэмплы — **uzu-drumkit** (bd/hh/oh/rim/cp/sh) и **Dirt-Samples**
  (metal/click/crackle), не дефолтные TR-909/808-банки.
- Кик — глубокий и глухой (низкий `cut`), на каждой доле; поверх — тихий
  `click:0` только как атака, не второй кик.
- Хэты — offbeat/8-е, редко 16-е; не заполнять всё.
- Rim/clap — точки, которые «всплывают» в секциях, а не постоянный брейк.
- Режимы: straight / broken / shuffle / strip — меняют микро-сдвиги, не состав.

## 3. Бас

- Саб ≤80 на A1, длинный decay.
- Mid-pulse — короткие ноты A2/E2, `cut` ~300, без мелодии.
- Октавы редко, как акцент; не «кислотный» питч-«пяу».

## 4. Гармония и дрон

- A-модальность: sine-дрон `[a2,e3]` с detune, изредка `[a2,bb3]` (b2 как
  краска). Это **не** наш обычный saw/Juno-пэд.
- Дрон входит не с первого такта: сначала металл/шум/винил, кик — на 8-м.
- Стаб `[a3,e4]` / `[a3,bb4]` — раз в 2–4 такта, не на каждую слабую долю
  (даб-стабы — только если просят явно). В нашем треке стаба нет: его роль
  играет редкий блайп.
- Блайп — высокий sine, редкий, в дилее.

## 5. Форма

```
INTRO 0–8      металл, шум, винил; без пэда и пульса
FLOOR 8–16     входит кик + клик-атака, текстура
PULSE 16–48    минимальный грув: кик, хэты, саб, дрон
BREAK 48–56    кик уходит, остаются пэд/шум/блайп
DRIVE 56–88    полный грув, rim/clap, срезы открываются
SHIFT 88–104   broken/shuffle, стабы, micro-сдвиги
OUTRO 104–120  кик + текстура, слои уходят
OUTRO 2 120–128  хвост без барабанов
```

## 6. Ошибки

- Мелодия/аккордовая прогрессия — это уже не минимал.
- Заполнять 16-е и «развивать» каждые 4 такта: развитие — медленное.
- Начинать с того же пэда, что в других треках; здесь интро — металл/шум.
- Дефолтные TR-909/808-банки «как везде»; лучше uzu/Dirt и характерные
  ваншоты.
- Много реверба: теряется пустота и низ.
- Даб-стабы на слабую долю без запроса.
- Смена уровней инструментов по секциям: включаем/выключаем слои, а не громкость.
- Дублировать шум (два одинаковых white/brown): один источник на текстуру.
