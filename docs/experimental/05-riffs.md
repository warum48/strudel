# Эйсид-риффы: как это работает

Цель — не «обыграть аккорд», а сделать **одноголосный ритмический мотив**,
который держит бас. Все 10 осцилляторов играют один и тот же рифф; меняется
только тембр. Риффы переключаются ручкой `riff` 0…11.

## 1. Чему учит TB-303

Roland TB-303 — монофония, saw/square, 24 dB lowpass, резонанс, accent,
slide, octave. Он проектировался как «замена бас-гитары», но стал
эйсид-инструментом: **простая последовательность + фильтр/акценты/слайды**
дают характер. В эйсид-хаусе «texture» важнее мелодии: одна фигура,
повтор, мутация, а не тема с аккордами.

## 2. Принципы риффа

1. **Одна линия.** Не арпеджио аккорда, не джазовая интервалика.
2. **16 шагов.** Бар = 16 шестнадцатых; рифф живёт в сетке.
3. **Повтор + микро-вариация.** Одна ячейка, на 4-й/8-й бар — изменение.
4. **Ритм вперёд, высота назад.** Много повторов ноты, паузы, синкопы;
   интервалы маленькие, октавные прыжки — как акцент.
5. **Accent / slide / octave.** Громкий удар, скольжение, скачок на октаву.
6. **Не «тю-тю-ту-ту».** Если каждая нота — новая высота через равные
   промежутки, это мелодия, а не рифф. Нужны повторы и паузы.

## 3. Двенадцать риффов трека

| `riff` | Имя | Идея |
|---|---|---|
| 0 | `acid` | классика 303: повторы d1, f1, g1, паузы, c2 |
| 1 | `roll` | трансовый роллинг: d1 на оффбитах, f1/g1/a1/c2 |
| 2 | `dnb` | разрежённый dnb-саб: d1, редкие f1/g1, c2 |
| 3 | `prod` | Prodigy-агрессия: плотные повторы d1/f1/g1, c2 |
| 4 | `off` | старт с паузы, оффбит-удар, g1/f1/c2 |
| 5 | `oct` | октавные прыжки d1–d2, верхний скрим |
| 6 | `stair` | одна нота → чуть выше → повтор: d1 d1 d1 → f1, потом g1 |
| 7 | `two` | две ноты ритмично: d1 f1 d1 f1, затем d1 a1 |
| 8 | `pedal` | педаль на d1, редкие c2/f1/g1 |
| 9 | `stab` | редкие удары d1, редкая c2, короткие паузы |
| 10 | `skip` | синкопы: d1 … d1 … c2 d1 |
| 11 | `crawl` | медленнее по 8-м: d1 d1 f1, потом a1/c2 |

### Примеры движения

**Повтор → чуть выше → повтор** (`stair`):

```text
d1 d1 d1 ~ d1 d1 f1 ~ d1 d1 g1 ~ d1 f1 d1 ~
```

Это не мелодия «вверх-вниз»: одна нота долбит ритм, потом соседняя выше
с slide, потом возврат. Slide делает переход, а не каждая нота.

**Чередование двух нот** (`two`):

```text
d1 f1 d1 f1 ~ d1 f1 d1 ~ d1 f1 ~ d1 f1 d1 ~
```

Две ноты создают грув; октава/третья нота — только как акцент.

Каждый рифф — 8 тактов, 16 шагов в такте. `ACCENT` — общий рисунок
акцентов (1 / .7 / .8), чтобы riff звучал ударно, а не ровной линией.

## 4. Как переключать

```js
// @switches riff=acid,roll,dnb,prod,off,oct,stair,two,pedal,stab,skip,crawl ...
const riff = slider(0, 0, 11, 1)
const RIFF = riff.pick([R1, R2, R3, R4, R5, R6, R7, R8, R9, R10, R11, R12])
```

Все WT/FM-слои используют `note(RIFF)`. Переключение `riff` меняет
**рисунок**, не тембр. FM5 играет тот же рифф октавой выше — это
октавное удвоение, не другой рифф.

## 5. Чего избегать

- арпеджио текущего аккорда;
- мелодия «вверх-вниз» через равные длительности;
- слишком много разных нот в одном баре;
- слайды на каждой ноте — slide должен быть акцентом, не фоном;
- ровный gain без accent-рисунка.
