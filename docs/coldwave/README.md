# Coldwave — плейбук

Холодный пост-панк/минимал-вейв конца 70-х — 80-х (Франция, Бельгия, Польша):
Kraftwerk + Joy Division + дешёвые синтезаторы. Не «мрачный синтвейв» и не
готика: **разреженность, механический ритм, ледяной тембр, пространство**.
Наши треки: `tracks/coldwave/01-cold-rooms.js` (база) и `02-cold-rooms-v2.js`
(короткий CHORUS, редкое соло в BREAK, арпеджио-стена в VERSE 2).

## 1. Звук

| Признак | Как делаем |
|---|---|
| Ритм | 4/4, механическая драм-машина: kick 1/3, rim/snare 2/4, хэты 8-ми |
| Темп | 100–115 BPM (cold wave); реже до 120–130 |
| Тональность | Dm / Am, модальный минор; гармония почти статична |
| Бас | короткие повторяющиеся ноты, корень/октава, низкий срез |
| Синты | тонкие моно-линии, Juno-пэд с долгой атакой и релизом |
| Гитара | угловатые короткие фразы, chorus, без «рока» |
| Вокал | низкий, отстранённый (у нас без вокала) |
| Микс | тёмный верх, длинные хвосты, много пауз |

Ключевое: **не заполнять**. 3–6 слоёв; пустота — часть жанра. Убрать слой
между секциями сильнее, чем добавить новый.

## 2. Ритм

- Kick: 1 и 3 (иногда 4-on-floor, но без хауса).
- Snare/rim: 2 и 4; лёгкий человеческий сдвиг не нужен — наоборот, жёстко.
- Хэты: ровные 8-е; 16-е только как редкая краска.
- Toms: заполнения в конце 4/8 тактов, не в каждом.
- Никакой фанковой синкопы и регги-«skank» — это другой жанр.

## 3. Бас

- Одна-две ноты на такт, повтор; иногда октава и b7.
- Звук: saw/square через низкий LP, короткий decay, `clip`, без яркого клика.
- Бас держит низ; пэд срезан сверху, чтобы не спорить.

## 4. Гармония

- Один аккорд на 2–4 такта; движение — верхними голосами и басом, не сменой
  аккордов каждые полтакта.
- Минор/дорийский; bVI и bVII как краска, без доминантовых кадансов.
- У нас: Dm-пэд + Bb/Gm как редкие сдвиги; мелодия в узком диапазоне.

## 5. Синты и обработка

- Пэд: sawtooth, `unison 3`, `detune`, `attack 0.6–1.5`, `release 2–4`,
  `lpf 600–1200`, большой `room`.
- Моно-лид/арп: тонкий square/saw, `lpf 1500–3000`, dotted-eighth delay.
- Гитара: короткий плак, `chorus`, `room`; играет «углами», не аккордами.
- Дилей: на 120 BPM доттированная восьмая ≈ 375 мс; у нас в циклах
  (`delaytime 0.375` = ⅜ такта).
- Реверб: длинный (2–4 с), но send умеренный; один общий размер IR
  (иначе Strudel пересобирает impulse response и рвётся звук).

## 6. Форма

Типично: intro (пэд+бас) → verse (барабаны+бас) → chorus (все слои) →
break (пэд/бас, без барабанов) → verse/chorus → outro (хвосты).
У нас 64 такта: INTRO 8 → VERSE 16 → CHORUS 12 → BREAK 8 → VERSE 16 →
OUTRO 4? — см. TIMELINE в треке.

## 7. Ошибки

- Слишком ярко/громко: coldwave не про «яркий прод», верх приглушён.
- Мажор и поп-прогрессии: почти всегда минор/модальность.
- Перегруз слоями и синкопой: теряется «холод».
- Короткий реверб: хвост — часть жанра.
- Много разных `roomsize` одновременно: в Strudel это убивает CPU.
